## How I work

- **Own the vertical slice.** Data model, API, UI, integration, release, and monitoring belong to one coherent solution.
- **Design for failure.** Timeouts, retries, idempotency, auditability, recovery paths, and useful logs are part of the feature.
- **Keep boundaries explicit.** Clear contracts and isolated adapters make payment providers and external APIs replaceable.
- **Use AI with engineering discipline.** AI tools accelerate research and implementation; tests, review, and production evidence decide what ships.
